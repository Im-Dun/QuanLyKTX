# Hệ Thống Quản Lý Ký Túc Xá

## Giới thiệu

Dự án được xây dựng bằng ASP.NET Core MVC và SQL Server nhằm hỗ trợ quản lý ký túc xá sinh viên.

## Công nghệ sử dụng

- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- SQL Server
- Bootstrap 5
- Chart.js

## Chức năng chính

- Đăng nhập hệ thống
- Dashboard thống kê
- Quản lý phòng
- Quản lý sinh viên
- Đăng ký phòng
- Quản lý hóa đơn
